## 我的解法
### 解法一：双指针
先排序，再按和 [[392. Is Subsequence|Is Subsequence]] 一样的使用双指针
```python
class Solution:  
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:  
        first = 0  
        second = 0  
        ransomNote = sorted(ransomNote)  
        magazine = sorted(magazine)  
        while True:  
            if first >= len(ransomNote):  
                return True  
            if second >= len(magazine):  
                return False  
            if ransomNote[first] == magazine[second]:  
                first += 1  
                second += 1  
            else:  
                second += 1
```

### 解法二： 使用哈希表
使用哈希表记录 magzine 中字母个数，在于ransomNote 中的字母进行比较
```python
class Solution:  
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:  
        temp_dict = defaultdict(int)  
        for m in magazine:  
            temp_dict[m] += 1  
  
        for n in ransomNote:  
            if temp_dict[n] > 0:  
                temp_dict[n] -= 1  
            else:  
                return False  
        else:  
            return True
```

## 灵神解法
直接使用 Counter 容器
```python
class Solution:  
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:  
        return Counter(ransomNote) <= Counter(magazine)
```
