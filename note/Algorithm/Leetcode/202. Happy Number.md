不可不吐槽一句，这个快乐数一点都不快乐。
1. 使用哈希存储以及得到过的值，判断是否进入了循环
```python
class Solution:  
    def isHappy(self, n: int) -> bool:  
        MAX = 2 ** 31 - 1  
        history = set()  
        if n <= 0:  
            return False  
        while n <= MAX:  
            temp = 0  
            while n > 0:  
                digit = n % 10  
                temp += digit ** 2  
                n //= 10  
            if temp == 1:  
                return True  
            n = temp  
            if n in history:  
                return False  
            history.add(n)
```

2. 使用[[快慢指针]]判断是否存在循环
```python
class Solution:  
    def isHappy(self, n: int) -> bool:  
        def get_next(num):  
            next_num = 0  
            while num > 0:  
                num, digit = divmod(num, 10)  
                next_num += digit ** 2  
            return next_num  
  
        slow = n  
        fast = get_next(n)  
        while fast != 1 and slow != fast:  
            slow = get_next(slow)  
            fast = get_next(get_next(fast))  
        return fast == 1
```
