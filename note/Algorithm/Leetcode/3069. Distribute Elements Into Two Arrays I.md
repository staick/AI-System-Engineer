简单的模拟题，直接按题目的意思编写即可
```python
class Solution:  
    def resultArray(self, nums: List[int]) -> List[int]:  
        arr1 = [nums[0]]  
        arr2 = [nums[1]]  
        n = len(nums)  
        last1 = nums[0]  
        last2 = nums[1]  
        for i in range(2,n):  
            if last1 > last2:  
                arr1.append(nums[i])  
                last1 = nums[i]  
            else:  
                arr2.append(nums[i])  
                last2 = nums[i]  
        return arr1 + arr2
```
