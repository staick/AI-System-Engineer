简单地按照题目的意思将最后的数插到最前面
```python
class Solution:  
    def rotate(self, nums: List[int], k: int) -> None:  
        """  
        Do not return anything, modify nums in-place instead.        
        """        
        while k:  
            num = nums.pop(len(nums)-1)  
            nums.insert(0,num)  
            k -= 1
```

根据下标规律，将对应的值放到新的列表中，再复制给原列表
```python
class Solution:  
    def rotate(self, nums: List[int], k: int) -> None:  
        """  
        Do not return anything, modify nums in-place instead.        
        """        
        n = len(nums)  
        temps = [i for i in range(n)]  
        for i, v in enumerate(nums):  
            temps[(i + k) % n] = v  
        nums[:] = temps
```
