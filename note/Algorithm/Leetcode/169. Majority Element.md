由于所求数的数量大于总个数的二分之一，则排序后中间的那个数就是所求的数
```python
class Solution:  
    def majorityElement(self, nums: List[int]) -> int:  
        nums.sort()  
        n = len(nums)  
        majority = nums[n//2]  
        return majority
```
时间复杂度 $O(nlogn)$ 空间复杂度 $O(n)$

类似于一种抵消的思想，抵消到最后胜出的肯定是符合要求的数
```python
class Solution:  
    def majorityElement(self, nums: List[int]) -> int:  
        ans = hp = 0  
        for num in nums:  
            if hp == 0:  
                ans, hp = num, 1  
            else:  
                hp = hp + 1 if ans == num else hp - 1  
        return ans
```
时间复杂度 $O(1)$  空间复杂度 $O(1)$
