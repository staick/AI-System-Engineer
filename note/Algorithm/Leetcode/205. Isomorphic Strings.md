## 我的解法
使用哈希表分别记录正反两个映射，遇到重复的返回 False，否则为 True
```python
class Solution:  
    def isIsomorphic(self, s: str, t: str) -> bool:  
        dict_s2t = {}  
        dict_t2s = {}  
        n = len(s)  
        for i in range(n):  
            if (s[i] in dict_s2t and dict_s2t[s[i]] != t[i]) or (  
                t[i] in dict_t2s and dict_t2s[t[i]] != s[i]  
            ):  
                return False  
            else:  
                dict_s2t[s[i]] = t[i]  
                dict_t2s[t[i]] = s[i]  
        else:  
            return True
```
