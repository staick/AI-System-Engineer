### Accept
```python
class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        s = set(nums)
        for x in range(1, 101 + k):
            if x * k not in s:
                return x * k
```
#### 复杂度分析
时间复杂度：$O(n)$
空间复杂度：$O(n)$
