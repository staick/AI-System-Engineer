## 弗洛伊德循环查找算法（Floyd's Cycle-Finding Algorithm）
弗洛伊德循环查找算法就是一种对于快慢指针的应用，通过定义两个指针
```python
slow = slow.next
fast = fast.next.next
```
当两个指针都进入循环时，`fast` 指针最终会追上 `slow` 指针。
所以，如果
```python
slow == fast
```
就证明有循环。
Time complexity: $O(n)$
Space complexity: $O(1)$

For example:
```
1 → 2 → 3 → 4 → 5
        ↑       ↓
        8 ← 7 ← 6
```
判断是否有循环的代码实现：
```python
def has_cycle(head):
	slow = fast = head
	
	while fast and fast.next:
		slow = slow.next
		fast = fast.next.next
		
		if slow == fast:
			return True
			
	return False
```

此外，更有意思的是：当两个指针相遇时，保持一个指针在相遇的位置，另外一个指针移动到开头的位置，然后同时移动两个指针，则当两个指针再次相遇的位置就是循环的入口位置。

原理分析：
假设：
- `a`：开始位置到循环入口的距离
- `b`：循环入口到相遇位置的距离
- `L`：循环长度

当第一次相遇时：
- slow distance = a + b
- fast distance = (a + b) * 2

因为两个指针相遇，所以 `fast` 比 `slow` 多走了一圈，即
```
(a + b) * 2 - (a + b) = L
```
所以有
```
a + b = L
```
然后有
```
a = L - b
```
即：从开始位置到循环入口位置的长度 = 从相遇位置到入口位置的长度

查找入口位置代码实现：
```python
def find_cycle_entry(head):
	slow = fast = head
	while fast and fast.next:
		slow = slow.next
		fast = fast.next.next
		
		if slow = fast:
			break
	else:
		return None
		
	p = head
	while p != slow:
		p = p.next
		slow = slow.next
		
	return p
```
