## 加法
思路：由于异或可以看成是无进位加法，所以我们只需另外记录进位再加到异或的结果中，就可以实现加法。而对于二进制来说，只有都为 1 的时候，才会发生进位。所以将两个数按位与再向左移动一位就可以得到进位信息。由于 Python 不像 C 一样有位数限制，所以需要通过一些特殊的处理来限制其位数。
```python
MASK = 0xFFFFFFFF  
MAX_INT = 0x7FFFFFFF  
  
def add(a, b):  
    sum_ = a  
    while b:  
        sum_ = (a ^ b) & MASK  
        b = ((a & b) << 1) & MASK  
        a = sum_
    return sum_ if sum_ < MAX_INT else ~(sum_ ^ MASK)
```

## 减法
减一个数相当于加上这个数的负数
```python
def neg(num):
	return add(~num, 1)

def minus(a, b):
	return add(a, neg(b))
```

## 乘法
乘法的实现类似于小学时的计算法方法，即用乘数的每一位来乘以被乘数
```python
def mul(a, b):  
    ans = 0  
    while b:  
        if b & 1:  
            ans = add(ans, a)  
        a <<= 1  
        b >>= 1  
    return ans
```
## 除法
除法的想法是每次找到被除数中最接近除数的部分，然后这个部分相除的结果为 1， 再计算剩余的部分
```python
def div(a, b):  
    x = neg(a) if is_neg(a) else a  
    y = neg(b) if is_neg(b) else b  
    i = 30  
    ans = 0  
    while i >= 0:  
        if (a >> i) >= b:  
            ans |= (1 << i)  
            x = minus(x, y << i)  
        i = minus(i, 1)  
  
    return neg(ans) if is_neg(a) ^ is_neg(b) else ans
```
