1. 使用命令查看当前显卡驱动支持的最高 CUDA 版本号
```shell
nvidia-smi
```
![[Pasted image 20260820154005.png]]
2. 如果支持的版本过低，可以在 [Nvidia 驱动官网](https://www.nvidia.com/en-us/drivers/)更新驱动，并下载支持版本的 [CUDA](https://developer.nvidia.com/cuda-downloads)

3. 在 [PyTorch 官网](https://pytorch.org/get-started/locally/) 根据电脑系统和 CUDA 版本号选择相应的选项，复制给出运行命令来进行安装
![[Pasted image 20260820161044.png]]

```
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu132
```

4. 运行如下 Python 程序，检查 PyTorch 环境和 CUDA 环境是否配置成功
```python
import torch  
  
print("PyTorch version:", torch.__version__)  
print("PyTorch CUDA version:", torch.version.cuda)  
print("CUDA available:", torch.cuda.is_available())  
  
if torch.cuda.is_available():  
    print("GPU:", torch.cuda.get_device_name(0))
```

>PyTorch version: 2.13.0+cu132
>PyTorch CUDA version: 13.2
>CUDA available: True
>GPU: NVIDIA GeForce RTX 3070 Laptop GPU
