## 概念
机器学习中的随机梯度下降法（Stochastic Gradient Descent, SGD）
$$
W \leftarrow W - \eta \frac{\partial L}{\partial W}
$$
- $W$：要更新的权重参数
- $\frac{\partial L}{\partial W}$：损失函数L关于W的梯度
- $\eta$：学习率
## 缺陷
1. 局部最优解：会陷入局部最优，尤其是在非凸函数中，难以找到全局最优解
2. 鞍点：陷入鞍点，梯度为0，导致训练停滞
3. 收敛速度慢：高维或非凸函数，收敛速度慢
4. 学习率选择要求高：学习率过大导致震荡或不收敛，过小则收敛速度慢

## 代码实现
```python
class SGD:  
    def __init__(self, lr=0.01):  
        self.lr = lr  
          
    def update(self, params, grads):  
        for key in params.keys():  
            params[key] -= self.lr * grads[key]
```
