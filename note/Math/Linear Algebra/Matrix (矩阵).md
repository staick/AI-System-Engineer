#### 三角矩阵
```python
v = np.array([1,2,3])  
A = np.tile(v, (3, 1))  
print(A)
[[1 2 3]
 [1 2 3]
 [1 2 3]]
  
print("下三角矩阵\n", np.tril(A))
下三角矩阵
 [[1 0 0]
 [1 2 0]
 [1 2 3]]

print("上三角矩阵\n", np.triu(A))
上三角矩阵
 [[1 2 3]
 [0 2 3]
 [0 0 3]]
```
