## Terminology 
### Model (模型)
$$y=f(x)$$
### Data Set (数据集)

- Training Set (训练集)：用于训练模型的数据
-  Validation Set (验证集) ：用于调节[[0. Conceptus#Hyperparameter (超参数)|超参数]]的数据
-  Test Set (测试集)：用于评估模型性能的数据
### Hyper Parameter (超参数)
> Parameters are learned by the model; hyperparameters are chosen by the engineer.

For example:
- learning rate
- number of training epochs
- batch size
- regularization coefficient
- maximum tree depth
- number of trees
- number of hidden layers
are hyperparameters.

### 概率相关
- prior：先验概率
- likelihood：似然
- posterior：后验概率
